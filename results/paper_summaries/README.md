# Supplementary CI baseline statistics

`ci_baseline_statistics.csv` and `ci_baseline_statistics.json` contain the
paired 30-epoch moving-block bootstrap results for the frozen global-CI and
receiver-wise-CI Cauchy baselines.  Each comparison uses 10,000 resamples, the
same timestamps and hidden truth as the proposed trajectory, and the proposed
method's post-initialization evaluation interval.

The files were generated by `run_motion_margin_ci_statistics.py` from the
already optimized trajectories.  The script reads trajectories only and
cannot alter factor construction, estimator parameters, or receiver choices.

## External LOCSP replication

`locsp_cr1_source_quotient_report.json` and
`locsp_cr2_source_quotient_report.json` contain the frozen external-validation
protocol, sample counts, point estimates, paired 10,000-replicate
segment-aware moving-block-bootstrap intervals, and replay-invariance checks.
The matching `*_metrics.csv` files provide compact trajectory-error tables.

The estimator used the M8T and Septentrio solutions; NovAtel INSPVA was held
out as reference.  M8T NavPVT and NavSatFix are two encodings of the same
physical solution and are therefore one evidence item under the proposed
source quotient.  These files validate source-cardinality control only.  They
do not constitute external validation of the three-receiver subset selector.

## Teacher-revision audit artifacts

`runtime_benchmark.csv/.json` contain five fresh HK Medium CPU timing repeats,
including the isolated topology-decision cost. `coordinate_calibration_manifest.json`
records the exact UrbanNav and LOCSP static transforms and the truth-free ENU
alignment convention. `pointcloud_map_manifest.json` records the official bag
topic, deterministic scan sampling, point counts, fixed-orientation policy, and
the disclosed post-evaluation detail selection used by Fig. 2.
