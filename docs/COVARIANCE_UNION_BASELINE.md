# Same-topology covariance-union baseline

This comparator receives exactly the singleton or pair selected by the
receiver-evidence topology. It therefore changes covariance construction, not
receiver selection.

For a pair, the union centre is parameterized as

`z_U(alpha) = (1 - alpha) z_1 + alpha z_2`, with `alpha` in `[0, 1]`.

At each scalar candidate, the implementation forms

`S_r = P_r + (z_U - z_r)(z_U - z_r)^T`

after the common 1 m covariance floor. The feasible common upper bound is

`P_U = S_1 + positive_part(S_2 - S_1)`.

SciPy `minimize_scalar(method="bounded")` minimizes `trace(P_U)` over
`[0, 1]` with absolute alpha tolerance `1e-8` and at most 200 iterations.
Trace is the rotation-invariant sum of marginal variances. If the scalar
solver reports failure, the declared fallback is `alpha = 0.5`; every call
exports success/fallback status, objective evaluations, and the minimum
member-constraint eigenvalue.

The manuscript audit used 2,432 selected-pair epochs. All 2,432 bounded
searches succeeded without fallback, with a median 31 objective evaluations;
the minimum feasibility eigenvalue was `-7.7e-9 m^2`, at numerical roundoff
scale. Over ten same-input batches, median Python construction time was
72.9 microseconds per envelope factor and 1009.6 microseconds per CU factor on
the disclosed workstation. These values are an implementation microbenchmark,
not a hardware-independent complexity claim.

The implementation is in `paper_pipeline/covariance_union.py`; unit tests are
in `tests/test_covariance_union.py`; full outputs are regenerated by the
`diagnostics` stage in `reproduce_paper.py`.
